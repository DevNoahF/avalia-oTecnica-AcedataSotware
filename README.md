# Avaliação Técnica - AcedataSotware

Projeto com 3 exercícios em Python, acessados via menu interativo.

## Exercícios

### 1. Cálculo de Salário (`exercicio1.py`)
Calcula o salário de um funcionário com base em valor/hora, horas trabalhadas e número de filhos. Aplica cotas de salário-família por faixa salarial e retorna salário bruto, salário família e salário líquido.

### 2. Sequência Numérica (`exercicio2.py`)
Recebe uma lista de números do usuário e exibe a sequência original e a versão ordenada em ordem crescente.

### 3. Fibonacci (`exercicio3.py`)
Gera os primeiros N números da sequência de Fibonacci e informa se o número N pertence ou não à sequência.

## Como Executar

```bash
python main.py
```

Escolha uma opção de 1 a 3 no menu e siga as instruções na tela.
